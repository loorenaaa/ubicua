## RECORDATORIO INTELIGENTE DE OBJETOS PERSONALES

### Descripción del problema
Es bastante habitual el salir de casa y olvidarte de objetos personales importantes, como por ejemplo las llaves de casa o los auriculares. El objetivo es crear un sistema capaz de reconocer cuando esto suceda y avisarnos. 

### Objetivos
- Identificar los objetos que el usuario considera importantes
- Detectar si el usuario lleva este objeto antes de salir de casa
- Avisar al usuario si no lleva alguno de estos

### Alcance
El sistema utilizará sensores inalámbricos asociados a estos objetos personales. Cuando el usuario se acerque a la puerta de salida el sistema comprobará si lleva estos objetos configurados y mostrará si falta alguno.

## ARMARIO INTELIGENTE

### Descripción del problema
En muchas ocasiones perdemos mucho tiempo buscando una prenda concreta o en decidir qué ponernos cada día. El objetivo es crear un sistema capaz de faciliarnos esta tarea.

### Objetivos
- Registrar las prendas que se encuentran en el armario
- Facilitar la búsqueda de una prenda concreta
- Proponer combinaciones de ropa con aquellas disponibles en el armario

### Alcance
El sistema utilizará etiquetas o dispositivos inalámbricos para identificar las prendas. Además este será capaz de proponer diferentes combinaciones de ropa.
